# Reaction Time Test

A simple browser-based reaction time game, controlled only with your spacebar!

Try it for yourself! : https://subtomic1833.github.io/ReactionTime/

##  How to Play

1. Press **SPACE** to begin.
2. Wait for the screen to change from **red** to **green**.
3. As soon as the screen turns green, press **SPACE** as quickly as possible.
4. Repeat for **5 rounds**.
5. At the end, view your:
   - Average reaction time
   - Best reaction time
   - Line graph showing your reaction time for each round

Pressing **SPACE** before the screen turns green ends the round with a "Too Early!" message.
